# NVP Operasional — contoh aplikasi

Prototipe aplikasi operasional (PWA, bisa dipasang di HP) PT Nuri Vira Pratama untuk Teknisi, Manager Operasional, dan Direktur:
pekerjaan refilling/pengadaan, tugas pemeriksaan APAR, pengajuan gaji & pembayaran, kas keluar, arsip PDF, notifikasi HP.

- Data hanya contoh dan tersimpan di perangkat masing-masing (belum terhubung ke viopran.com).
- `app.source.jsx` = kode sumber; `app.js` = hasil kompilasi yang dipakai halaman.
